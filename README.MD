# Project Overview ( Complete)
## Project Overview  ( POE Part 1)
For POE Part 1, I started developing a website for Fresh Choice Dairy, a local family-owned dairy business. The main purpose of the website is to make it easier for customers to learn more about the business, view its products and find ways to contact them.<br><br>
I created different pages for the website, including Home, About, Product, Enquiry and Contact. I used HTML to build the basic structure and content of each page. I also followed the ideas from my original proposal when deciding how I wanted the website to look and feel.<br><br>
My aim was to keep the website simple, clear and easy to navigate. I wanted users to be able to move between the different pages without getting confused and easily find the information they are looking for. This part of the project helped me turn my original planning and ideas into an actual website.

## Project Overview  ( POE Part 2)
For POE Part 2, I focused more on improving the design and overall look of the Fresh Choice Dairy website. I used CSS to style the different pages and make the website feel more consistent.<br><br>
I added the colours and typography that I planned in my original proposal and worked on the spacing, layout, navigation and buttons. I also added hover effects and made the website responsive so that it can adjust better to different screen sizes.<br><br>
I also improved the Enquiry page by styling the form and adding a Google Form where users can send an enquiry. My main goal for this part was to make the website look better while also keeping it simple and easy for users to understand. Overall, Part 2 helped me improve the basic website from Part 1 and make it feel more complete and user-friendly.

## Project Overview (POE Part 3)
For Part 3, I added basic JavaScript to make the Fresh Choice Dairy website more interactive. Visitors can search for products on the Product page and click product images to see them in a larger lightbox. I also added simple validation to the Enquiry and Contact forms so that visitors get feedback when filling in their details. I worked on SEO by adding page descriptions, image alternative text, robots.txt and sitemap.xml. The website still needs to be tested after publishing, and the sitemap links need to be updated with the live website address.

## Intended Users
The website is aimed at people who want to learn about Fresh Choice Dairy, browse its dairy products or contact the business with questions.

## Website Features
- **Home:** Introduction to Fresh Choice Dairy and navigation to the other pages.
- **About:** Background information about the business.
- **Product:** Dairy product information, product search and a lightbox for larger images.
- **Enquiry:** An enquiry form with basic validation and an embedded Google Form for sending enquiries.
- **Contact:** Contact information, a map and a form that prepares an email in the visitor's email application.
- **Responsive design:** CSS layout adjustments for different screen sizes.
- **Basic SEO:** Meta descriptions, alternative text for images, robots.txt and sitemap.xml.

## POE Part 3 - JavaScript and Lightbox
I added simple JavaScript to the Product, Enquiry and Contact pages. The Product page now has a search box that hides products that do not match the search, and clicking an image opens a larger view (lightbox). The lightbox can be closed with the X button, Escape key or by clicking outside the image. The Enquiry form checks required fields and displays a sample acknowledgement; it does not send data to the business. The Google Form remains available for actual enquiries. The Contact form checks the information and opens the visitor's email application with a prepared message; sending still requires the visitor to confirm it.
